# sorting-algorithms
This program is a simple implementation of various sorting algorithms in C#. The implemented sorting algorithms include:

-Bubble Sort <br />
-Selection Sort <br />
-Insertion Sort<br />
-Merge Sort<br />
-Quick Sort<br />

The program provides a graphical user interface (GUI) using Windows Forms. Users can choose to either input their own array or generate a random array of specified length. The sorting algorithms can be applied to the array, and the sorted array and the time taken for the sorting process are displayed.

Additionally, the program includes error handling for input validation, such as checking for proper numeric input.
